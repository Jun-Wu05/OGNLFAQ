## L1 单步写法

### 大小写转换

- **写法名**：字段值大小写统一
- **原句示例**：`<% 字段.toLowerCase() %>` / `<% 字段.toUpperCase() %>`（FAQ 1.8）
- **适用语法**：OGNL `<% %>`

### split 取位

- **写法名**：字段值分割后取单个元素
- **原句示例**：`<% original_log.split(",")[1] %>`（FAQ 1.6）
- **适用语法**：OGNL `<% %>`

### 加减乘除 / 比较

- **写法名**：字段间加减乘除、`==` 比较
- **原句示例**：`<% a 运算符 b 运算符 c %>` / `<% a == b %>`（FAQ 1.21 / 1.14）
- **适用语法**：OGNL `<% %>`

## L2 多步/嵌套写法

### A.B 点号替换

- **写法名**：JSON 中 `A.B` / `A.B.C` 点号替换为下划线再映射
- **原句示例**：`<% original_log.replaceAll("\"(.*?)\\.([a-zA-Z0-9_]+)\":", "\"$1_$2\":") %>`（FAQ 1.1 方法一）
- **适用语法**：OGNL `<% %>`

### 三元取值去空白

- **写法名**：条件取值，`XFF1` 存在取 `XFF1` 否则取 `sip`（去两端空白判空）
- **原句示例**：`<% XFF1.trim().equals("") ? sip : XFF1 %>`（FAQ 1.9）
- **适用语法**：OGNL `<% %>`
- **扩展**：多级优先取值 A>B>C —— `<% (A != null && !A.trim().equals("") ? A : (B != null && !B.trim().equals("") ? B : C)) %>`

### 多重数组投影合并

- **写法名**：多重数组中提取同一字段值合并
- **原句示例**：`<% A.{b} %>`（FAQ 1.3）
- **适用语法**：OGNL `<% %>`

### 条件匹配再解析

- **写法名**：字段值匹配多种元素 / 模糊包含
- **原句示例**：`field8 in ['A','B','C']` / `original_log like ' A ' or original_log like ' B '`（FAQ 1.5）
- **适用语法**：OGNL `<% %>`（条件表达式，配合三元）

### 非空字段拼接

- **写法名**：筛选 doc 中非空字段名并以逗号拼接
- **原句示例**：`{% def fields = new String[] {"a","b","c","d"}; Arrays.asList(fields).stream().filter(p -> doc.get(p) != null && doc.get(p).toString().length() > 0).collect(Collectors.joining(",")) %}`（FAQ 1.12）
- **适用语法**：Painless `{% %}`
- **注**：FAQ 标注该写法在 3.5 及以上版本生效。

### `distinct` 去重

- **写法名**：从 URL 数组抽域名后去重
- **原句示例**：`{% 集合?.stream().map(m -> { def url = m.get("url"); def startIndex = url.indexOf("://") + 3; def endIndex = url.indexOf("/", startIndex); if (endIndex == -1) { endIndex = url.length(); } return url.substring(startIndex, endIndex); }).distinct().collect(Collectors.toList()) %}`（FAQ 1.4）
- **适用语法**：Painless `{% %}`
- **要点**：`?.` 安全导航避免空指针；`distinct()` 去重后 `collect(Collectors.toList())` 返回 List，亦可 `collect(Collectors.joining(","))` 返回字符串。

## L3 陷阱写法

### 域名还原（DNS 完整域名带括号数字）

- **写法名**：Windows DNS 日志 `(20)optimizationguide-pa(10)googleapis(3)com(0)` 还原为标准域名
- **原句示例**：`<% original_log.replaceAll("^\\(\\d+\\)|\\(\\d+\\)$", "").replaceAll("\\(\\d+\\)", "\\.") %>`（FAQ 1.15）
- **适用语法**：OGNL `<% %>`
- **要点**：先去首尾 `(数字)`，再把中间 `(数字)` 替换为 `.`。两步 `replaceAll` 顺序不能反。

### 正则抽邮箱

- **写法名**：从邮件头/收件人数组中正则抽取标准格式邮箱并合并为数组
- **原句示例**：`{% def result = new ArrayList(); def emailPattern = /[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\.[A-Za-z]{2,}/; ... def matcher = emailPattern.matcher(addr); if (matcher.find()) { result.add(matcher.group()); } ... return result; %}`（FAQ 1.23）
- **适用语法**：Painless `{% %}`
- **要点**：正则 `/[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\.[A-Za-z]{2,}/`；遍历数组逐项 `matcher.find()` + `matcher.group()` 收集；可按 `isto` 等条件过滤。

### 递归扁平化（多重数组嵌套 JSON 提取）

- **写法名**：多重数组里还嵌一层 JSON，提取相同字段值合并
- **原句示例**：`<% @com.alibaba.fastjson.JSON@parseObject(log).{product} %>`（FAQ 1.3 补充）
- **适用语法**：OGNL `<% %>`
- **要点**：用 fastjson 静态调用解析嵌套 JSON，再用 OGNL 投影 `.{字段}` 跨多层数组提取；注意白名单——`com.alibaba.fastjson.JSON` 在白名单内（见 SKILL.md 白名单段，#18 落地）。

### base64 判定再解码（条件分支陷阱）

- **写法名**：字段同时可能是 base64 密文与明文，先判定再解码避免明文被解出乱码
- **原句示例**：`<% @com.hansight.dataviewer.utils.Base64@Base64Decode(original_log.matches('^[A-Za-z0-9+/]*={0,2}$') ? original_log : original_log) %>`（FAQ 1.18）
- **适用语法**：OGNL `<% %>`
- **要点**：`com.hansight.dataviewer.utils` 在白名单内；先用正则判定是否 base64，再决定是否解码。

### 科学计数法时间值处理

- **写法名**：科学计数法时间戳映射为标准时间字段
- **原句示例**：`<% timestamp.replaceAll("e\\+\\d+", "").replaceAll("\\.", "").replaceAll("(\\d{10}).*", "$1000") %>`（FAQ 1.16）
- **适用语法**：OGNL `<% %>`

## 回归必测点与陷阱补强（Issue #14 / #15 / #16）

> 本段在 #11 主条目之上追加**回归锚点与陷阱补强**，不重写主条目。每个必测点结构：「写法 + 回归点（拿什么贴平台实跑） + 期望值 + 陷阱说明」。判分锚点 = 现场平台实跑、首选制逐字判等（SSOT：`docs/eval/README.md`）。skill 改动后必跑这些点，防止回归。

### L1 单步回归必测点（#14）

| 写法 | 回归点 | 期望值 | 陷阱说明 |
| ---- | ------ | ------ | -------- |
| 大小写转换 | 字段值含大小写混合，转小写/大写 | 转换后的统一大小写串 | 标量题平台类型盲显示——值对即判对，但输出侧提示「标量字段注意类型」（数值字段拿到字符串现场不可用，平台判不出） |
| 三元取值去空白 | 字段为空串/纯空白，三元判空取另一字段 | 非空字段值 | `trim()` 后用 `equals("")` 判空，不能直接 `== ""`；空白串不等同空串 |
| split 取位 | 字段含分隔符多元素，取指定位置 | 该位置元素值 | `split(",")[1]` 是 0 基索引；空字段 split 后越界报错 |
| `==` 比较 | 两字段值相同/不同 | `true` / `false` | 布尔题平台类型盲显示，值对即判对，类型错判不出 |
| 加减乘除 | 13 位时间戳自增 5 分钟 | 计算后数值 | 字符串时间戳须先 `* 1` 强制转数字再算，否则按字符串拼接 |

**标量类型盲区提示（faq-01/04/05）**：标量题（`4` / `true` / `2000`）平台是类型盲显示，逐字判等只判值、不卡类型——值对但类型错（数值字段拿到字符串）现场不可用但平台判不出。skill 输出侧须提示「标量字段注意类型」，不在判分环节补探针（探针本身也是标量显示、探不了类型）。详见 `docs/eval/results.md` 类型盲区结论标注。

### L2 多步/嵌套回归必测点（#15）

| 写法 | 回归点 | 期望值 | 陷阱说明 |
| ---- | ------ | ------ | -------- |
| A.B 点号替换 | JSON 含 `A.B` / `A.B.C`，替换点号再映射 | 替换后可正常解析的字段 | `replaceAll` 正则转义；嵌套层需二次替换（剩点没换完） |
| 多重数组投影合并 | 多重数组提取同一字段合并 | 合并后的数组/List | 投影 `.{字段}` 跨多层；漏抽浅层判错 |
| `distinct` 去重 | URL 数组抽域名后去重 | 去重后的域名集合 | **集合相等判分陷阱**：未去重会原样返回带重复的多重集（如 `[x,y,x,z]`），按集合双向比对判错（多一个重复即错） |
| 条件匹配再解析 | 字段匹配多种元素 / 模糊包含 | 匹配后的值 | `in` / `like` 条件配合三元；多条件 or 拼接 |
| 非空字段拼接 | 筛选 doc 中非空字段名逗号拼接 | 拼接后的字符串 | `doc.get(p) != null && length() > 0` 双重判空；3.5+ 版本生效 |

**集合相等判分陷阱补强**：L2 的 `distinct` 去重 / 数组投影类题，平台必须显示 **List（JSON 数组形态 `[…]`）**，拼接成字符串判**错**；集合按「元素不多不少、顺序不敏感」双向比对平台**原样输出**的多重集——漏一个判错、多一个/含未去重重复判错。平台是哑执行器，模型没去重就显示没去重，看结果即知。

### L3 递归/正则/类型陷阱回归必测点（#16）

| 写法 | 回归点 | 期望值 | 陷阱说明 |
| ---- | ------ | ------ | -------- |
| DNS 域名还原 | `(20)a(10)b(3)com(0)` 还原标准域名 | `a.b.com` | 两步 `replaceAll` 顺序不能反：先去首尾 `(数字)`、再把中间 `(数字)` 换 `.` |
| 科学计数法时间 | `1.67757122349e+12` 转标准时间戳 | 处理后 10 位 + `000` | 去 `e+\d+`、去小数点、截 10 位补 `000`；正则顺序敏感 |
| base64 判定再解码 | 字段可能密文/明文混合 | 解码后明文（密文项）/原值（明文项） | 先正则判定是否 base64 再决定解码，否则明文被解出乱码 |
| 递归扁平化 | 多重数组嵌一层 JSON，提取同字段 | 扁平化后的数组 | **递归陷阱**：只抽浅层会漏深层，判错；需跨多层投影 |
| Map 筛 min | Map 按 `类型:等级` 筛后取 min | 筛选后的最小值 | 类型/等级匹配 + min 聚合，类型陷阱 |

**⚠️ 重点必测：faq-11 域名去重**——评测结论点名 L3 注入 FAQ 例子后不再集体崩（天花板 L3 全过、地板/中档 L3 仅 faq-11 错），但 **faq-11 域名去重仍是最易漏去重的点**，作 skill 回归**必测项**。补强陷阱：① 递归只抽浅层会漏深层；② 未去重返回带重复多重集判错。skill 每次改动后必跑 faq-11，确认域名去重不漏。
