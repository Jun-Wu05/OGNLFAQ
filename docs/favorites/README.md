# 收藏 · 跑通表达式

> 经现场验证**跑通**的表达式条目存入本目录，跟随仓库可 git 管理（SSOT：PRD「实现决策 › 收藏落盘」Issue #20）。
> **收藏 ≠ Q&A**：跑通只进收藏；Q&A 追加交给后续带标准的 skill 完成（`CONTEXT.md`「边界与非目标」：不自动写入 Q&A 文档）。

## 条目结构

每条收藏含：

- **样例日志**：跑通时所贴的日志原文（脱敏后）。
- **意图**：自然语言描述想做什么。
- **期望效果**：「应新增字段 xxx，值应为 yyy」可逐字判等形式。
- **跑通表达式**：现场平台实跑通过、显示值与期望效果逐字判等的表达式（含 `<% %>` / `{% %}` / `%{ }` 边界符）。
- **适用语法**：OGNL / Painless / 字段引用。
- **验证日期**：现场实跑通过的日期。

## 命名约定

按 `<日期>-<写法或场景>.md` 命名，如 `2026-08-10-domain-dedup.md`。一条文件可含多条同类收藏。
